# New Fashion Cafe

A modern static fashion-store website for **New Fashion Cafe**, a local clothing store in Hubli, Karnataka, India. Owner: Gopal.

**Live demo:** https://your-project-name.vercel.app

> This is a demo website. Products, reviews, prices, phone number and email are sample data. Cart, wishlist, orders and payments are simulated in the browser. Nothing is sent to a server.

## Features

- 14 pages: Home, Shop, Product, Categories, Wishlist, Cart, Checkout, Order Confirmation, Order Tracking, Lookbook, Style Guide, Size Guide, About, Contact
- 28 demo products with SVG-generated clothing visuals
- Search, filters (gender, category, size, price, rating, stock) and sorting
- Cart, wishlist and orders saved in LocalStorage
- Simulated checkout, order confirmation and order tracking
- Find My Size recommendation tool
- Dark mode, mobile menu, toast notifications, countdown timer
- Contact form with validation
- Floating WhatsApp button (demo number)

## Tech Stack

HTML5, CSS3, Vanilla JavaScript, LocalStorage. No frameworks, no backend, no build step.

## Project Structure

```
New-Fashion-Cafe/
├── index.html, shop.html, product.html, ... (all pages)
├── css/style.css
├── js/data.js      (product data)
├── js/main.js      (all site logic)
└── assets/favicon.svg
```

## Run Locally

1. Clone the repo: `git clone https://github.com/karannavalgund-cpu/New_Fashion_Cafe.git`
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.

## Deployment

Deployed as a static site on Vercel. No build command or output directory is needed.
